# Power Dairies Management System

A comprehensive web-based dairy farm management system designed to streamline dairy operations in Kenya.

## 🌟 Features

### For Administrators
- User management (Admin, Collectors, Farmers)
- Milk collection oversight and approval
- Payment processing with M-Pesa integration
- Feed inventory management
- Claims and dispute resolution
- Comprehensive reporting and analytics

### For Milk Collectors
- Digital milk collection recording
- Farmer management and assignment
- Payment tracking
- Real-time notifications

### For Farmers
- Milk production tracking and records
- Payment history and receipts
- Livestock management (cows, health records)
- Feed ordering and inventory
- Claims submission
- Real-time notifications

## 🛠️ Technology Stack

- **Backend:** Django 5.2.14 (Python)
- **Frontend:** HTML5, CSS3, JavaScript, Bootstrap 5
- **Database:** SQLite (Development), PostgreSQL (Production)
- **Payment Integration:** M-Pesa Daraja API
- **Charts:** Chart.js
- **PDF Generation:** ReportLab

## 📋 Prerequisites

- Python 3.14.4 or higher
- pip (Python package manager)
- Git
